1. Download erlang https://www.erlang.org/downloads
2. Download RabbitMq https://www.rabbitmq.com/docs/install-windows
3. After Installing Go to Command Prompt and Navigate to C:\Program Files\RabbitMQ Server\rabbitmq_server-3.13.3\sbin
4. Execute the command : rabbitmq-plugins.bat enable rabbitmq_management 
5. rabbitmq-server.bat start and rabbitmqctl.bat stop
